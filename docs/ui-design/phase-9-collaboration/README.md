# Phase 9 Controlled Collaboration Workflows

This UI artifact was generated before production code changes for Phase 9.

The mockup keeps the simplified desktop direction: project and room navigation
on the left, an IM-style room timeline in the center, and a right-side workflow
review panel. It shows a bounded workflow launcher for handoff, review loop,
and panel discussion modes; timeline cards for handoff, review requested,
review completed, and workflow completed; and explicit max-round/stop-condition
controls.

Files:

- `index.html` - static mockup source.
- `phase-9-collaboration.png` - captured UI image.
