# Phase 3 Task Grouping UI Design

This artifact previews the visible Phase 3 timeline change before production
UI code changes. The design keeps Phase 2's project room shell, then groups a
single user instruction, task-created system event, assignment rows, and
multiple run cards into one compact task block.

Files:

- `index.html`: static HTML/CSS design artifact.
- `phase-3-task-grouping.png`: rendered 1600x960 reference image.

The production implementation may stay simpler than the mockup, but it should
preserve the core interaction: one instruction creates one shared task, and the
room timeline makes the grouped assignments and run cards visible without
turning the desktop into a kanban board.
