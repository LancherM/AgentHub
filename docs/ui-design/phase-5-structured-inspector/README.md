# Phase 5 Structured Inspector UI

This design artifact precedes Phase 5 production UI work.

- Scope: rename the run-centric inspector into a workgroup review inspector.
- Tabs: Brief, Context, Artifacts, Checks, Risks, Memory, Audit.
- Simplification: Handoff and Compare are no longer top-level tabs; they stay inside Artifacts as engineering evidence sections.
- Boundary: existing review IPC remains authoritative; no merge, apply, push, cleanup, external publishing, or automatic memory approval controls are added.

Files:

- `index.html` - static mockup used for implementation direction.
- `phase-5-structured-inspector.png` - rendered screenshot of the mockup.
