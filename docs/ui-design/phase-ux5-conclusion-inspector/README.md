# UX5 Conclusion Inspector

Design artifact for `docs/interaction-optimization-roadmap.md` phase UX-5.

The mock defines the intended inspector default:

- the Brief tab opens on conclusion, suggested decision, changed output, checks,
  and risks before evidence details;
- blocking risks are pinned at the top of the review surface;
- manual next actions route to secondary tabs without applying or mutating code;
- raw logs, context previews, full diffs, exit metadata, and handoff remain
  behind Context, Artifacts, Checks, Risks, Lifecycle, and Audit.
