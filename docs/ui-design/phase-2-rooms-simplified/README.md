# Phase 2 Rooms Simplified Design

This design artifact is the UI gate output for Phase 2 of
`docs/local-ai-workgroup-roadmap.md`.

Files:

- `index.html`: static HTML/CSS mockup for the simplified rooms layout.
- `phase-2-rooms-simplified.png`: rendered 1600x960 review image.

Design intent:

- Keep the current conversation/run-card workflow recognizable.
- Rename the generic thread navigation into project Rooms.
- Use the left sidebar for project, room, team, task status, and local-first
  indicators.
- Keep the center as an IM-style room timeline backed by conversation messages
  and run cards.
- Keep the right side as the review surface for selected run evidence.

This artifact does not change production desktop UI. Production implementation
should wait for explicit user approval of the design direction.
