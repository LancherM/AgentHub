# Phase 6 Artifact Model UI

This design artifact precedes Phase 6 production UI work.

- Scope: promote important run evidence into named, reusable local artifact rows and timeline chips.
- Backing model: existing `run_artifacts` remain the v0 storage source.
- UI target: keep the Phase 5 Workgroup Inspector shell, enrich the Artifacts tab with title, type, source run/task/thread, creator, summary, local availability, and bounded preview.
- Boundary: no artifact editing, versioning, external publishing, vector search, merge, apply, push, or automatic memory approval.

Files:

- `index.html` - static mockup used for implementation direction.
- `phase-6-artifact-model.png` - rendered screenshot of the mockup.
