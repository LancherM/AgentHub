# Phase 4 Timeline Events UI

This design artifact precedes Phase 4 production UI work.

- Scope: render the room center pane as an auditable work stream over existing conversation messages.
- Boundary: raw logs, diffs, verification rows, risks, and memory details remain lazy-loaded through the inspector.
- Layout: keep the Phase 2/3 desktop shell, simplify the center timeline into readable event cards, and retain the right review panel as contextual drill-down.

Files:

- `index.html` - static mockup used for visual direction.
- `phase-4-timeline-events.png` - rendered screenshot of the mockup.
