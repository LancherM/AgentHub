# Phase 8 Team Role Configuration

This UI artifact was generated before production code changes for Phase 8.

The mockup keeps the current desktop shape: project and room navigation on the
left, the active Team workspace in the center, and a right-side role review
panel. It shows preset roles, a custom QA role, safe editable fields, executor
availability, permissions, context policy, approval policy, recent tasks, and
linked memory.

- `index.html` - static mockup source.
