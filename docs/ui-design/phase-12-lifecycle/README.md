# Phase 12 Lifecycle UI Design

This directory contains the UI design artifact generated before Phase 12
production UI changes.

- `index.html`: static desktop mockup for explicit apply and worktree lifecycle
  controls.
- `phase-12-lifecycle.png`: rendered screenshot of the mockup.

The design keeps the existing room-first layout and adds a compact right-side
Lifecycle inspector with retained worktree state, cleanup confirmation, apply
preview, risk gate, and audit trail.
