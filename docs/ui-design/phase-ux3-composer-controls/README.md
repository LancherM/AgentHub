# Phase UX-3 Composer Controls UI

This design artifact precedes the Phase UX-3 production UI work.

- Scope: make the composer a discoverable command surface for agent/role targets, common slash prompts, context mode, and submit fan-out.
- Boundary: this phase does not add a new slash-command backend, global command palette, or adapter execution behavior.
- Layout: target chips sit above the input, autocomplete is anchored to the active `@` or `/` token, context mode uses segmented controls, and the submit button reports expected target count.

Files:

- `index.html` - static mockup used for visual direction.
- `phase-ux3-composer-controls.png` - rendered screenshot of the mockup.
