# Phase UX-1 Quiet Transcript UI

This design artifact precedes the Phase UX-1 production UI work.

- Scope: make the room transcript read as a conversation where durable agent answers are the main rows.
- Boundary: run lifecycle events, exit codes, logs, diffs, checks, and risks remain reachable through review/inspector surfaces.
- Layout: active runs appear as compact progress rows; completed runs with assistant output collapse to a small review affordance.

Files:

- `index.html` - static mockup used for visual direction.
- `phase-ux1-quiet-transcript.png` - rendered screenshot of the mockup.
