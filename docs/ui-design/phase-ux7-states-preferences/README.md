# Phase UX-7 States, Preferences, and Keyboard Polish

This artifact captures the UX-7 direction before implementation.

- Empty states use a compact action rail: primary next action, secondary local navigation, and a short boundary note.
- Codex/Claude unavailable states show the failed detection result, PATH evidence, and a copyable local verification command.
- Harmless preferences persist locally: selected project/room, active workspace, composer context mode, inspector tab, and sidebar density.
- `Cmd+K` opens a local command palette for primary desktop actions after project and room actions are available.
