# Phase 7 Knowledge / Memory Workspace

Static UI design artifact for `docs/local-ai-workgroup-roadmap.md` Phase 7.

The design keeps the existing local desktop shell: project and room navigation
on the left, a workspace list in the center, and review/governance details on
the right. It shows memory proposals, approved and rejected memory, thread
summaries, decisions, source links, related tasks/runs, and audit history
without adding hosted collaboration or automatic memory approval.
